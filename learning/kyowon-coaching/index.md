## 빠른 기준

- 코치는 대신 해결하지 않는다. 참가자가 Codex와 직접 대화하게 만든다.
- 오늘 목표는 완성품이 아니라 `0 -> 0.1`의 감각이다.
- 이미지 생성 세션은 모델 비교보다 입력표, BOOK별 기준, QC 기준을 먼저 고정한다.
- 대량 생성은 한 번에 많이 만드는 일이 아니라 작은 독립 생성 작업을 안정적으로 반복하는 일이다.
- 끝났다는 판단은 실제 샘플과 체크 가능한 QC 기준으로 한다.
