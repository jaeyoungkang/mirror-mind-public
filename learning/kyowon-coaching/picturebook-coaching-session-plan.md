# 교원 이미지 스튜디오 코칭 세션 계획안

## 목표

참여자의 핵심 기대는 "이미지 생성 품질"이다. 따라서 세션의 중심은 AI 일반론이 아니라, `image prompt.xlsx`의 33개 프롬프트와 `BOOK1`~`BOOK7` 그룹을 기준으로 **대량 생성에서도 개별 생성에 가까운 품질을 유지할 방법**을 찾는 것이다.

오늘의 작은 성과:

- 30개 이상 배치 테스트를 위한 입력표 점검
- BOOK별 캐릭터/그림체 일관성 기준 정리
- 짧은 프롬프트 보강 규칙 만들기
- 1차 자동 QC와 2차 사람 QC 기준 만들기
- 실패 작업 기록 양식 만들기

핵심 질문:

> GPT 이미지 생성이 부족한가, 아니면 현재 입력표가 BOOK별 일관성을 유지하기에 충분한 정보를 매 요청에 주지 못하고 있는가?

## 확인된 자료

`image prompt.xlsx`

- 33개 프롬프트 포함
- `BOOK1`~`BOOK7` 그룹
- 공통 출력: PNG, 416x416
- 컬럼: 번호, 그룹명, 프롬프트, 이미지 유형, 비율, 주의사항
- BOOK명은 첫 행에만 있고 후속 행은 비어 있음
- 일부 프롬프트는 충분히 길지만, 일부는 `a small raccoon looking up at the night sky`, `cooled and hardened from lava`처럼 너무 짧음

슬라이드 자료

- 이미지 유형 A: 단어용 소컷
- 실패 예시 포함
- 대량 생성 시 품질 저하, 캐릭터/그림체 일관성 문제가 핵심

## 세션 메시지

초반에 이렇게 잡는다.

```text
오늘은 이미지 생성 품질을 중심에 두겠다.
다만 모델이 알아서 일관성을 보장해준다고 기대하지 않고,
BOOK별 기준, 레퍼런스, 프롬프트 구조, 생성 단위, QC 기준을 같이 설계해서
개별 생성에 가까운 품질을 배치에서도 유지할 수 있는지 확인해보겠다.
```

기술 방향은 이렇게 정리한다.

- Codex 내장 image generation: 실험/프로토타입용
- 실제 대량 생성: API 기반 반복 실행이 적합
- 대량 생성은 "한 프롬프트에 여러 장을 몰아넣기"가 아니라 "독립된 생성 작업을 큐로 안정적으로 반복"하는 구조
- 품질이 중요하면 기본 단위는 `1 이미지 = 1 생성 요청`

## 진행 흐름

### 1. 실제 병목 재확인

질문:

- 개별 생성이 더 좋았다고 판단한 기준은 무엇인가?
- 리스트형 대량 생성에서 무엇이 나빠졌나? 캐릭터, 화풍, 디테일, 장면 일치 중 무엇인가?
- BOOK별로 고정해야 하는 것은 캐릭터인가, 화풍인가, 배경 세계관인가?
- 레퍼런스 이미지는 BOOK 전체 기준인가, 장면별 기준인가?
- 30개 중 몇 개가 실패하면 재생성 대상으로 볼 것인가?

### 2. 입력표 점검

먼저 `image prompt.xlsx`를 생성 가능한 작업표로 고친다.

필수 점검:

- 비어 있는 BOOK명을 모든 행에 채운다.
- 이미지 유형과 텍스트 허용/금지 여부를 분리한다.
- 짧은 프롬프트에는 BOOK 기준, 캐릭터 기준, 스타일 기준, 금지 조건을 자동 주입한다.
- 공통 레퍼런스와 BOOK별 레퍼런스를 분리한다.
- 스타일명과 긴 스타일 프롬프트 매핑을 만든다.

권장 컬럼:

- `그룹명/BOOK`
- `순번`
- `이미지 이름`
- `장면 설명`
- `원본 프롬프트`
- `보강 프롬프트`
- `스타일명`
- `이미지 유형`
- `비율`
- `공통 레퍼런스`
- `BOOK별 레퍼런스`
- `텍스트 허용 여부`
- `네거티브 조건`
- `QC 상태`
- `실패 사유`

### 3. 이미지 생성 실험

동일 BOOK에서 짧은 프롬프트와 긴 프롬프트를 각각 고른다.

비교 실험:

1. 원본 프롬프트 그대로 생성
2. BOOK 기준/스타일/네거티브 조건을 주입한 보강 프롬프트로 생성
3. 가능하면 개별 생성과 큐형 배치를 비교

비교 기준:

- 장면 설명과 일치
- 같은 BOOK 안의 그림체 일관성
- 캐릭터 생김새 일관성
- 텍스트/로고/워터마크 혼입 없음
- 교육용 콘텐츠로 부적절한 요소 없음

### 4. 30개 배치 테스트 설계

30개 전체를 한 번에 해결하려 하지 않는다. 먼저 BOOK별 대표 샘플을 승인한다.

흐름:

1. BOOK별 대표 샘플 1~2개 생성
2. 사람이 캐릭터/그림체 기준 승인
3. 승인된 BOOK만 나머지 이미지 생성
4. 생성은 `1 이미지 = 1 생성 작업`으로 반복
5. 결과를 파일명/폴더 규칙에 맞춰 저장
6. 자동 QC로 누락과 매칭 확인
7. 사람 QC로 캐릭터/그림체/장면 일치 확인

파일명 예시:

```text
BOOK1/BOOK1_001_아침장면.png
BOOK1/BOOK1_002_밤하늘.png
BOOK2/BOOK2_001_지층단면.png
```

## QC 기준

1차 자동 QC:

- 예상 작업 수와 실제 결과 수 일치
- 작업 번호와 결과 파일 매칭
- BOOK별 폴더 저장 여부
- 파일명 규칙 준수
- 실패 작업 기록 여부

2차 사람 QC:

- 캐릭터 생김새 유지
- 그림체 유지
- 장면 설명과 결과 이미지 일치
- 교육용 콘텐츠로 부적절한 요소 없음
- 영어 글자, 캡션, 말풍선, 워터마크, 로고, 읽을 수 있는 텍스트 없음

## 바로 쓸 프롬프트

```text
우리는 이미지 생성 서비스의 배치 테스트 흐름을 설계하려고 한다.
현재 image prompt.xlsx에는 33개 프롬프트가 있고, BOOK1~BOOK7 그룹명이 있다.
공통 출력 형식은 PNG, 416x416이다.
같은 BOOK 안에서는 캐릭터 생김새와 그림체가 유지되어야 한다.

아래 입력표와 실패 예시를 보고 다음을 정리해줘.

1. 현재 입력표에서 BOOK별 일관성을 깨뜨릴 수 있는 문제
2. 짧은 프롬프트를 보강하는 규칙
3. BOOK별 대표 샘플 승인 흐름
4. 30개 배치 테스트 절차
5. 1차 자동 QC와 2차 사람 QC 기준
6. 실패 작업 기록 양식

바로 구현 방법을 제안하지 말고, 먼저 현재 자료에서 확인해야 할 빈칸과 질문을 정리해줘.
```

## 코치가 붙잡을 원칙

1. 이미지 생성 품질을 중심에 둔다.
2. 모델 선택보다 입력 구조와 QC 기준을 먼저 고정한다.
3. 대량 생성은 "한 번에 많이"가 아니라 "작은 독립 작업의 안정적 반복"으로 설명한다.
4. 짧은 프롬프트는 그대로 보내지 말고 BOOK 기준과 금지 조건을 주입한다.
5. 3000개 확장은 30개 테스트에서 실패율, 재생성률, 비용, 소요 시간을 측정한 뒤 논의한다.

## 위험 신호

- 모델 이름 비교로 바로 넘어간다.
- 30개 전체 생성부터 시작한다.
- BOOK별 기준 없이 프롬프트만 반복 실행한다.
- 결과는 나왔지만 성공/실패 판정 기준이 없다.
- 코치가 직접 답을 주고 참가자가 검수 기준을 만들지 않는다.
